# VIT Gradebook — React

Responsive GPA/CGPA calculator with a minimal landing page and three routes.

## Run locally
Install Node.js 18+, then run from this directory:

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Pages
- `/` landing page
- `/gpa` GPA calculator
- `/quick-cgpa` quick CGPA calculator
- `/any-sem-cgpa` any-semester CGPA calculator

The calculations run in the browser; no backend is required. Theme choice is saved locally.
